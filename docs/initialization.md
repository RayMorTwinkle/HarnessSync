# 本机首次初始化 · v0.3

初始化被拆成三个阶段：扫描、引导、AI 整理。用户无需手动勾选每个普通技能和指令段落，但不同版本和语义冲突不能靠时间戳静默决定。

## 1. 扫描快照

扫描四种 Harness 的已知用户、兼容目录与已绑定项目路径，不做全盘搜索。输出真实目录、所有入口、完整资源指纹、名称和版本关系、主全局指令、覆盖文件、共享指令及规则片段。

同一真实目录的链接合并统计；内容相同的不同副本仍保留位置。完整指纹不同才判为内容变体；链接或其他问题导致无法获得完整指纹时，标为未验证，不假装内容相同或不同。断链单独报告，不中断兄弟目录扫描。

清单和交接提示词保存在 `~/.harness-sync/onboarding/<id>/`，属于本机资料，不进入源 Git。

扫描条目带 `origin` 和 `originReason`：`user`、`platform`（Claude synced 与 plugins）、`tool-managed`（`.skill-lock.json` / `skill-lock.json` / `skills-lock.json`）、`system`（`.system` 与 Codex 标记）。锁文件支持各根目录及其父目录，格式损坏只警告；来源 URL 单列 `sourceUrl`。清单汇总默认可导入用户数、默认排除的托管数和本机保留数。默认只处理有效、未管理且未保留的用户技能。

无效包分别说明缺少 SKILL.md、非法 name 的实际值及建议 kebab-case 名称、空 description，不自动修复。

## 2. 安装管理技能

仅安装或更新中文管理包到检测到的 Harness。此步骤复用正常部署、差异检查和快照，但计划限定管理 Skill，不顺带发布其他待部署配置，不改写原有全局指令。

引导不是迁移完成。界面只显示“管理技能已部署，等待交给 AI 整理”。

## 3. AI 整理与发布

用户复制中文提示词，交给任意已支持 Harness。提示词给出固定清单 ID、完整 CLI 路径和整理边界，要求 AI 视扫描资料为数据，不执行技能脚本。

默认推荐共享通用技能；明确属于设备或项目的保留范围。相同内容可合并来源；同名异版、原始规则矛盾等真正分歧集中询问。已有管理技能不重复导入，异常包保留并报告。

AI 先保存源配置、展示批量结果与部署差异。需要把主全局指令整体变为合成结果时，通过 `onboard stage-instructions` 登记扫描指纹。主文件此时不变；有适用源片段、指纹仍匹配后，正常部署才会进行替换并保留原件快照。可用 `onboard unstage-instructions` 取消登记。

非主规则片段、链接和未生效副本不允许借此接口静默清理。若外部来源仍可能影响上下文，应在完成报告中保留这一限制。

## 链接与本机保留

用户链接技能集中为一个问题，默认导入副本，可逐项选择外部保留。导入从真实目录读取，原始入口记录到设备 `origins`，链接真实源记录到 `originRealPaths`。部署始终复制；原生链接使用 `skills import <链接入口> --adopt` 显式接管，导入时不替换，计划显示“以副本替换链接”。apply 快照保留链接文本，回滚恢复原链接；目标链接或完整包变化会拒绝旧计划。只允许末级接管链接，链接祖先仍拒绝写入。

`onboard ignore <绝对入口路径...>` 将选择保留的所有入口记录到设备 `ignoredNativePaths`，扫描标记 `ignored`，GUI 显示“外部保留”。部署预览只显示保留信息、不冲突且不写入，后续提示词不再建议这些入口。`--remove` 取消保留；已管理目录不能保留。共享兼容目录仍不允许接管，保留并报告。

## 开发源刷新

`skills refresh <id>` 或 `skills refresh --all` 从本机记录的源目录刷新完整包，包含资源新增、修改、删除和执行位；保留 scope、enabled、displayName。刷新只更新源库，之后需要预览部署。源技能改名或无效会拒绝刷新。`status` 和 `doctor` 的 `sourceUpdates` 报告“源目录有更新”及读取失败；开发目录不是自动同步部署。

设备路径不写入共享源配置。旧 manifest 的绝对 source 可只读查询，下一次源修改时迁到设备 origins；保留的 Git 历史不会重写。

## 跨设备同步（可选）

本机整理完成后的可选步骤：`hsync sync setup --create` 或 `hsync sync setup --url <仓库URL>`。按已安装版本的帮助配置；此工作流只引用同步命令，不把本机初始化描述成已完成跨设备同步。

## 既有本机验收记录（v0.2）

- 原始四份全局指令在管理技能引导前后逐字节一致。
- 管理包包含中文正文、中文说明、中文 Codex 显示元数据与初始化指南。
- Codex 和 Claude Code 的真实只读会话成功运行管理 CLI；均返回 `healthy: true`、零待部署变更。
- 本机存在断链、无效元数据以及包内链接，扫描会如实标识；不会在引导阶段自动替用户清理这些资料。
- 全量已有技能与全局规则的语义迁移尚待用户把生成的提示词交给所选 Harness；没有把准备好引导误报为已迁移全部配置。
